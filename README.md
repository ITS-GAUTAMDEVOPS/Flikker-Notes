# About Flikker Notes
Flikker Notes is a web-based notes application built using modern web technologies. It is designed with a clean and premium interface inspired by Mac and iPad UI, making everyday note-taking feel simple, smooth, and visually beautiful.

The goal of Flikker is not just to store notes — it is to make writing and organizing ideas feel better.

# Features
♡ Create and write your own notes.
♡ Add and edit text easily.
♡ Organize your thoughts in a clean interface.
♡ Edit notes whenever you want.

# Text Customization
Flikker gives you control over how your notes look:

♡ Change Font
♡ Adjust Text Size
♡ Change Text Color
♡ Set Text Alignment
♡ Customize your writing according to your style
